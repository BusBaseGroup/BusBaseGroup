BusBase – First Bus-style passenger display + 20 second live refresh
==================================================================

- Live vehicle feeds refresh every 20 seconds.
- First Eastern Counties passenger journeys automatically switch to a First Bus-inspired
  purple / magenta / blue onboard display.
- Lynx journeys keep the BusBase/Lynx passenger display.
- The passenger screen uses the built-in shared clear-AI engine from
  /tracker/admin/announcement-bank.js.
- Browser/system speech synthesis is not used.
- The clear-AI engine assembles Next stop / This stop announcements from the shared
  AI phrase and stop-name bank and uses the full physical journey stop sequence.
- First's 2024 refreshed brand was used as the visual direction; this is a BusBase
  passenger-information design rather than an official First Bus software screen.
