Connection & help

Same Firebase project as vehicle checks: put the Firebase project configuration in the FIREBASE_CONFIG object near the bottom of this HTML file. Enable Email/Password sign-in in Firebase Authentication. This page uses the same signed-in user accounts as the defect site if both use the same Firebase project.
Defect matching: adjust CHECK_COLLECTION, CHECK_FIELDS and STATUS_VALUES in the script to match the records saved by your existing vehicle-checks page. By default the site listens for check documents in vehicleChecks and matches a fleet number or registration with the selected operating date. Red is shown for a reported defect, green for a completed check, amber for no check. If a vehicle appears multiple times, its worst active result is shown.
Security: install the supplied firestore.rules alongside your existing rules, merging the allocations rule into your existing rules rather than replacing unrelated collections. Only authorised users should be able to modify allocations. Never put an admin password or service account private key in this website.
